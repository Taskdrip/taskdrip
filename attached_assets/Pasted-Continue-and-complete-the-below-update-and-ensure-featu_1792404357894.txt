### Required Download Workflow

The workflow must work as follows:

STEP 1: User visits the downloads homepage.

STEP 2: User searches for a file and clicks View Details.

STEP 3: If the user is not logged in, redirect them to the registration/login page.

STEP 4: After registration or login, allow access to the individual download details page.

STEP 5: User clicks the primary button labelled:

"GET FREE DOWNLOAD"

STEP 6: Open the configured Adsterra Smartlink in a new tab or through the configured redirect method.

STEP 7: After the first Adsterra redirect has been initiated, mark the download's advertising requirement as completed for that user and that specific download.

STEP 8: Display or unlock the actual download button.

The unlocked button should read:

"DOWNLOAD NOW"

STEP 9: When the user clicks DOWNLOAD NOW, take them directly to the original file download link.

IMPORTANT:
- Do not send users through Adsterra again after the advertising requirement has been completed.
- Do not make the actual download link available before the advertising requirement is completed.
- Store the advertising completion state securely on the backend, not just in frontend JavaScript or local storage.
- Track completion separately for each user and download.
- Prevent duplicate ad redirects for an already unlocked download.
- Handle browser popup blockers gracefully.
- Do not claim that an advertisement has completed simply because a click event occurred if the redirect was blocked.
- Provide a retry option if the advertising redirect cannot be opened.
- Make the system configurable so the admin can enable or disable the advertising requirement.

### User Notice

Display this short note below the primary button:

"To access your free download, you'll first be redirected to our advertising partner. Once you've completed this step, your download button will be unlocked. You can then download your file directly without additional redirects."

Make the message clear, friendly and professional.

### Security

Never expose private storage paths or sensitive download URLs unnecessarily.

Use secure server-side authorization and expiring download URLs where supported.

Do not allow users to bypass the advertising requirement by manually accessing the download endpoint.
