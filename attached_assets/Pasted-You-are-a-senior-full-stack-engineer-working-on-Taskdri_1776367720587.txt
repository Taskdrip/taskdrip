You are a senior full-stack engineer working on Taskdrip™, a Web3 influencer marketplace.

Your task is to build a COMPLETE P2P MARKETPLACE SYSTEM with:

1. Admin-controlled escrow
2. Admin-controlled fees (P2P + platform-wide)
3. Full admin visibility over all transactions
4. In-app chat between buyer, seller, and admin

Ensure clean architecture, scalability, and security.

========================
1. P2P MARKETPLACE HUB
========================

Create page:
/p2p-hub

Tabs:
- Crypto Trades
- Products
- Services

Each listing must include:
- Title
- Type (crypto/product/service)
- Description
- Price / rate
- Payment method
- Featured image (for product/service)
- User info (rating, username)
- “Accept Offer” button

Add:
+ “Create Listing” button

========================
2. LISTING SYSTEM
========================

Users can:
- Create listings (crypto, product, service)
- Submit for admin approval

Status:
- pending
- approved
- rejected

Only approved listings go live.

========================
3. ESCROW TRANSACTION SYSTEM
========================

When a user clicks “Accept Offer”:

- Create transaction
- Assign:
  buyer_id
  seller_id
  admin_id
- Set status:
  pending → funded → delivered → completed

Flow:

1. Buyer accepts offer
2. Buyer sends funds to ADMIN escrow wallet
3. Buyer clicks “Mark as Paid”
4. Seller delivers product/service/crypto
5. Buyer clicks “Confirm Received”
6. Admin releases funds to seller

========================
4. ADMIN ESCROW CONTROL
========================

Admin must:

- View all transactions
- Manually confirm payment received
- Release funds to seller
- Cancel/refund transaction

Admin dashboard page:
/admin/p2p-transactions

Display:
- Transaction ID
- Buyer
- Seller
- Amount
- Fee
- Status
- Actions (Release / Refund / Dispute)

========================
5. P2P FEE SYSTEM (ADMIN CONTROLLED)
========================

Create table:

p2p_fee_config:

- fee_type (percentage/fixed)
- fee_value
- min_fee
- max_fee

Admin page:
/admin/p2p-fees

Admin can:
- Set fee per transaction type
- Update anytime (no redeploy)
