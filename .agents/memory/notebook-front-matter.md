---
name: Notebook front matter
description: Page-count and numbering rules for optional introductory notebook designs.
---

Optional introductory pages print before the main notebook pages. The configured writing-page count remains the count of usable writing pages; introductory pages are not given writing-page numbers. Physical print totals, print validation, KDP eligibility, and cover-spine calculations include every selected introductory page.

**Why:** The admin asked for selected intro designs before the notebook pages that start counting. Editors need a stable writing-page count without undercounting the actual print file.

**How to apply:** When changing notebook page generation or print guidance, translate from physical page index to writing-page index after the intro sequence. Leave intro pages unnumbered and begin writing-page numbers/dates at 1.
