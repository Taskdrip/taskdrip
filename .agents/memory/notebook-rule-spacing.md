Notebook writing pages should have clean, evenly spaced rules. Keep the spacing setting easy to find and make sure its selected interval is reflected consistently in both the live proof and generated print output.

**Why:** The user reported inconsistent line spacing in notebook pages and requested a setting to make the lines look clean and professional.

**How to apply:** When changing notebook rule rendering or settings, preserve a user-adjustable physical interval and keep the editor proof and exported PDF in sync.
